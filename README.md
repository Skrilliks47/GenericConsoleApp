## Краткое описание

Данное консольное приложение демонстрирует использование обобщённых типов (Generics) в C#.

## Реализованные классы

### 1. GenericClass<T>
Обобщённый класс с private свойством и методами для установки и получения значения.

### 2. StaticMethodsClass
Класс с двумя статическими методами:
- `Swap<T>` - обмен значениями между двумя переменными
- `PrintCollection<T>` - вывод элементов коллекции

### 3. MinMaxClass
Класс для нахождения максимального и минимального значения с использованием CompareTo.

### 4. OperationResult<T>
Класс-контейнер для описания результатов операции:
- IsSuccess - флаг успешности
- Value - значение результата
- ErrorMessage - сообщение об ошибке

### 5. Person
Пример класса с переопределённым методом ToString().

## Основной функционал

1. Создание контейнеров для хранения данных типов float и bool
2. Обмен значениями переменных различных типов
3. Вывод элементов коллекции
4. Нахождение минимального и максимального значений
5. Создание объектов с обработкой ошибок через фабричные методы
